I'm **BaoLT** (a.k.a. *luthebao* / *ironman*). I build native desktop
applications, command-line tools, and runtime-level software — mostly in
[Odin](https://odin-lang.org/) and [Rust](https://www.rust-lang.org/) — and I
write up the interesting ones here.

## What I work on

- **Native, dependency-light apps.** I like shipping a single binary that talks
  straight to the data source — no backend to deploy, fewer moving parts.
- **Developer tooling.** Small, sharp command-line utilities that earn their
  place in a daily workflow.
- **Keeping old things alive.** Legacy formats and protocols are worth saving;
  sometimes that means forking a runtime and adding the missing piece.

A few recent projects: an RTMP-capable Flash Player emulator, a native terminal
for the Vietnamese stock-futures market, and a multi-purpose macOS CLI. They all
have write-ups on the [home page]({{ '/' | relative_url }}#posts).
